# T05 비교 보고서 — A 인계 상태

이 보고서는 A 종료 상태다. B는 아직 실행하지 않았으며 전체 과제 완료를 주장하지 않는다. 개선 대상은 실제 주가 정보판의 js/replay.js 정규화 입력 검증이다. [고정 검사와 공통 조건](PLAN.md), [원본 인수인계](../../HANDOFF.md)를 기준으로 B가 이어받는다.

## 이름을 가린 측정표

| 구분 | 실제 작업시간 | 실제 사용자 요청 | 오류 회차 | 고정 검사 통과 |
|---|---:|---:|---:|---|
| 세션 1 | 172.369초 (2.873분) | 1회 | 3회 | 시작 3/10 → 종료 7/10 |
| 세션 2 | 미실행 | 미실행 | 미실행 | 미실행 |

공통 상한은 각각 30분·사용자 작업 요청 5회다. 내부 도구 호출은 요청 수에 포함하지 않는다. 세션 1의 기준 실행·수정 후 실행·새 폴더 실행 각각에 FAIL이 있으므로 오류 회차는 3회다. 기존 회귀 검사는 통과했으며 고정 검사 회차와 구분한다. 시간은 준비 커밋 등록 이후 실제 A_START부터 로컬 인계 증거 확정까지 측정했다. 이후 문서 업로드는 인계 자료 등록이다. 사용자 플랫폼에 기록된 시작 시각은 확인하지 못했다.

## 짧은 확인 방법 4줄

위치: 이 저장소의 t05/input-validation-a 브랜치와 HANDOFF.md로 이동한다.

행동: 새 폴더에 해당 브랜치 복제 → Node.js 24 이상 확인 → node tests/t05-fixed-validation.cjs 실행의 3단계다.

통과 모습: 현재 A 상태의 재현은 V01~V07 PASS, V08~V10 FAIL이다. 최종 B 완료의 통과는 10 PASS/0 FAIL·종료 코드 0이다.

안 될 때 모습: 결과가 7 PASS/3 FAIL과 다르거나 실행이 중단되면 A 인계 재현 실패다. 최종 검사에 FAIL이 남으면 기능 미완료다.

## AI와 학생 판단

AI에게 맡긴 일: 코드 분석·고정 검사 구현·시간값 검증 수정·결과 및 인수인계 작성이다.

직접 판단한 일: 학생 확인 전이다. 실제 선택을 학생이 직접 확정해야 한다.

AI 제안을 따르지 않은 일: 학생 확인 전이다. 실제 거절한 제안 또는 없었던 이유를 직접 확정해야 한다.

도구 선택 기준: 학생 확인 전이다. 측정표와 실제 사용 경험을 보고 한 문장으로 확정한다. 서로 다른 작업 단계이므로 이 표만으로 모델 전반의 우열을 단정하지 않는다.

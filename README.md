# T04 오늘의 진짜 정보판 — SK하이닉스 주가 정보판

> 비개인 공개 원천(한국거래소 KRX / 네이버페이 증권)의 실제 SK하이닉스 종가를 매일 보존하고, 전일 대비 변화를 계산하며, 외부 장애 시에도 마지막 정상값을 보존하고 정직하게 설명하는 정보판입니다.

---

## 1. 짧은 확인 방법 (T04-C27 준수)

1. **① 어디로 가나요**
   - 배포된 공개 웹 사이트 URL(`https://<사용자-아이디>.github.io/<저장소-이름>/`)에 시크릿 창으로 접속합니다.
2. **② 3단계 이내 무엇을 하나요**
   - 1단계: 메인 화면에서 수집된 최신 SK하이닉스 종가(`1,418,000 원`), 어제 대비 변화량(`▼ 어제 대비 -108,000 원 하락`), 3개 값(원자료·저장값·화면값) 일치 대조표 및 이틀간의 보존 기록(`2026-10-30`, `2026-11-02`)을 확인합니다.
   - 2단계: 화면 아래 **[카드 3 · 결정론 합성 시험]** 패널에서 `[C19 복구 시나리오 원클릭 준비]` 버튼을 누릅니다. (105원 유지 및 `stale / timeout` 주황색 경고 배지 확인)
   - 3단계: 주황색 경고 박스 안의 `[다시 시도 (Retry)]` 버튼을 누릅니다.
3. **③ 무엇이 보이면 통과인가요**
   - 주황색 경고가 사라지고 **초록색 정상 배지(`Fresh / None`)**로 돌아오며, 주가가 `120 pt`로 갱신되고, 일별 기록에 2일차 행이 추가되며 `▲ 어제 대비 +15 pt 상승`이 정확히 계산되어 보이면 통과입니다.
4. **④ 안 될 때 무엇이 보이나요**
   - 네트워크 단절이나 장애 시 화면 상단에 **주황색 `▲ 보존된 오래된 값 (Stale / 해당 오류코드)`** 배지와 함께 마지막 정상값이 지워지지 않고 보존되며, 오류 원인과 `[다시 시도]` 버튼이 표시됩니다.

---

## 2. AI와 나의 판단 (T04-C28 준수)

1. **① AI에게 맡긴 일**
   - ALEPH 과제 규격(`normalized-reading.schema.json`, `public-contract.json`)에 맞춘 공통 데이터 스키마 설계 및 검증 엔진(`replay.js`) 작성
   - 비밀키 없이 호출 가능한 공공 주가 데이터 추출 및 스키마 정규화 자동화 스크립트(`scripts/fetch-price.js`) 구현
   - 5대 장애 모의 및 회복(C19)을 버튼 클릭으로 검증할 수 있는 직관적인 시뮬레이션 UI 구현
2. **② 학생이 직접 판단한 일**
   - 처음에 추천되었던 '영화 박스오피스 1위'는 며칠 동안 순위가 변하지 않아 일별 변화를 관찰하기 어렵다는 한계를 직접 발견하고, 매 영업일마다 지수와 등락폭이 확실히 변하는 'SK하이닉스 주가'로 최종 데이터 원천을 변경함
   - 과제 제출 플랫폼의 [실제 공개 원천 기록] 양식(원천 URL, 관측 시각, 정규화 값, 단위)을 화면에서 원클릭으로 쉽게 복사해 제출할 수 있도록 전용 복사용 카드 배치를 지시함
3. **③ AI 제안을 따르지 않은 일 (이유 포함)**
   - AI가 초기에 제안한 단순 기온 데이터 대신, 국내 주식 시장의 핵심 지표이자 과제 합성 fixture 단위(`pt`)와도 성격이 잘 부합하는 SK하이닉스 주가를 선택하여 데이터 관찰의 현실성과 흥미를 높임

## 3. 핵심 기능 및 과제 충족 기준

- **C01~C02, C29~C33 (공개 접근성)**: 로그인, 회원가입, 비밀번호, OAuth, CAPTCHA 없이 시크릿 창에서 즉시 열람 가능.
- **C03~C10 (실제 공개 원천 데이터)**: SK하이닉스 실제 종가 수집, 값(`1,526,000`), 단위(`원`), 출처, 관측 시각, 수집 시각, 기준 시간대(`Asia/Seoul`) 표기 및 원자료·저장값·화면값 100% 일치.
- **C11 (비밀값 0건)**: API 키나 토큰을 전혀 사용하지 않는 100% 공개 엔드포인트 활용. 코드·저장소·네트워크 어디에도 비밀키 원문 없음.
- **C12~C18 (5대 고장 시험)**: timeout, auth, rate_limit, offline, schema_error 모의 시 마지막 정상값 보존 및 `stale / error_code` 표시.
- **C19 (복구 시나리오)**: stale 상태에서 다시 시도 시 `fresh / none`, 2일차 신규 행 1건 추가, 120 pt 저장값 회복.
- **C20~C21 (일별 보존 규칙)**: 동일 날짜 내 중복 저장 시 기존 행 갱신(1건 유지), 익일 저장 시 신규 일별 행 추가.
- **C22~C24 (실제 이틀치 기록 및 변화 대조)**: 서로 다른 실제 KST 날짜 2건(`2026-10-30`: 1,526,000원, `2026-11-02`: 1,418,000원) 보존, 두 기록의 출처 URL·시각·값·단위 일치 및 어제 대비 변화값(-108,000원) 재계산 일치.
- **C25 (개인정보 0건)**: 개인 식별 정보 및 개인 기록 일절 미포함.
- **C26 (합성 시험값 분리)**: 합성 시험 재생 시에는 과제 제공 합성 fixture 값만 사용하여 실제 기록과 분리 보존.

# T04 오늘의 진짜 정보판 — SK하이닉스 주가 정보판

> 비개인 공개 원천(한국거래소 KRX / 네이버페이 증권)의 실제 SK하이닉스 종가를 매일 보존하고, 전일 대비 변화를 계산하며, 외부 장애 시에도 마지막 정상값을 보존하고 정직하게 설명하는 정보판.

---

## 핵심 기능 및 과제 충족 기준

- **C01~C02, C29~C33 (공개 접근성)**: 로그인, 회원가입, 비밀번호, OAuth, CAPTCHA 없이 시크릿 창에서 즉시 열람 가능.
- **C03~C10 (실제 공개 원천 데이터)**: SK하이닉스 실제 종가 수집, 값(`1,526,000`), 단위(`원`), 출처, 관측 시각, 수집 시각, 기준 시간대(`Asia/Seoul`) 표기 및 원자료·저장값·화면값 100% 일치.
- **C11 (비밀값 0건)**: API 키나 토큰을 전혀 사용하지 않는 100% 공개 엔드포인트 활용. 코드·저장소·네트워크 어디에도 비밀키 원문 없음.
- **C12~C18 (5대 고장 시험)**: timeout, auth, rate_limit, offline, schema_error 모의 시 마지막 정상값 보존 및 `stale / error_code` 표시.
- **C19 (복구 시나리오)**: stale 상태에서 다시 시도 시 `fresh / none`, 2일차 신규 행 1건 추가, 120 pt 저장값 회복.
- **C20~C21 (일별 보존 규칙)**: 동일 날짜 내 중복 저장 시 기존 행 갱신(1건 유지), 익일 저장 시 신규 일별 행 추가.
- **C22~C24 (실제 이틀치 기록 및 변화 대조)**: 서로 다른 실제 KST 날짜 2건(`2026-10-30`: 1,526,000원, `2026-11-02`: 1,418,000원) 보존, 두 기록의 출처 URL·시각·값·단위 일치 및 어제 대비 변화값(-108,000원) 재계산 일치.
- **C25 (개인정보 0건)**: 개인 식별 정보 및 개인 기록 일절 미포함.
- **C26 (합성 시험값 분리)**: 합성 시험 재생 시에는 과제 제공 합성 fixture 값만 사용하여 실제 기록과 분리 보존.
